# Practica Guiada - Sistema de Gestion Academica

Este material esta basado en el `README.md` del proyecto principal.

Objetivo: que practiques los fundamentos antes (o en paralelo) de implementar `proyecto.cpp`.

## Estructura

- `TEORIA.md`: resumen de teoria necesaria.
- `00-fundamentos/`: modelado de datos y flujo del programa.
- `01-lista-enlazada/`: gestion de estudiantes con lista enlazada simple.
- `02-arreglo-dinamico/`: copia de lista a arreglo dinamico.
- `03-ordenamientos/`: burbuja, seleccion, insertion, quicksort, mergesort.
- `04-busquedas/`: lineal en lista y binaria en arreglo ordenado.
- `05-recursividad/`: promedio general e impresion recursiva.
- `06-integrador/`: mini sistema completo con menu.

## Como practicar (sin humo)

1. Resolve cada carpeta en orden.
2. No saltees validaciones de entrada y casos borde.
3. En cada ejercicio, primero escribi casos de prueba manuales.
4. Recién despues, integra todo en `proyecto.cpp`.

## Criterios de calidad

- No repetir logica: extrae funciones.
- Mantener consistencia de nombres (`codigo`, `nombre`, `promedio`).
- Evitar acoplamiento innecesario entre menu y estructuras.
- Verificar siempre: lista vacia, un solo nodo, elementos repetidos.

## Definicion de listo

Un ejercicio esta listo cuando:

- Compila.
- Funciona en casos normales y casos borde.
- Podes explicar por que elegiste esa estructura y ese algoritmo.
