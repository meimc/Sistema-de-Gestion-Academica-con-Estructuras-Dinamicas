# Ejercicio 04 - Busquedas

## Objetivo

Aplicar busqueda lineal en lista y busqueda binaria en arreglo ordenado.

## Consigna

1. Implementa busqueda lineal por `codigo` en la lista enlazada.
2. Implementa busqueda binaria por `codigo` en arreglo ordenado por `codigo`.
3. Reporta claramente:
   - Encontrado / No encontrado
   - Posicion (en arreglo) o referencia de nodo (en lista)

## Criterios de aceptacion

- Lineal funciona aunque no haya orden.
- Binaria solo se ejecuta si el arreglo esta ordenado por `codigo`.
