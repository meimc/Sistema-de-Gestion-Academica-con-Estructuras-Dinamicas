# Ejercicio 05 - Recursividad

## Objetivo

Resolver operaciones de la lista usando funciones recursivas.

## Consigna

1. Implementa una funcion recursiva para sumar promedios.
2. Con esa suma, calcula el promedio general del grupo.
3. Implementa impresion recursiva de estudiantes.

## Criterios de aceptacion

- La recursion tiene caso base correcto.
- No hay recursion infinita.
- Resultado correcto para lista vacia, 1 nodo y multiples nodos.
