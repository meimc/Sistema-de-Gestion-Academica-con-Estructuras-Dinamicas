# Ejercicio 03 - Ordenamientos

## Objetivo

Implementar los algoritmos exigidos sobre el arreglo dinamico auxiliar.

## Consigna

Implementa y prueba:

1. Burbuja por `promedio`.
2. Seleccion por `codigo`.
3. Insertion Sort por `nombre`.
4. Quick Sort por `promedio`.
5. Merge Sort por `codigo`.

En cada caso, mostrar arreglo antes y despues.

## Criterios de aceptacion

- Cada algoritmo ordena por la clave correcta.
- Se mantienen los datos coherentes tras ordenar.
- Funciona con tamanios pequenos y medianos.

## Plus recomendado

Medi y compara tiempos con `n=100`, `n=1000`, `n=5000` (siempre con datos consistentes).
