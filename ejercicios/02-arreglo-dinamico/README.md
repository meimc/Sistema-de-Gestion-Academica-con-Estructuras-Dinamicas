# Ejercicio 02 - Lista a arreglo dinamico

## Objetivo

Copiar los estudiantes de la lista enlazada a un arreglo dinamico para procesarlos.

## Consigna

1. Cuenta cuantos nodos tiene la lista.
2. Reserva memoria dinamica para ese numero de estudiantes.
3. Copia los datos nodo por nodo al arreglo.
4. Muestra el arreglo generado.
5. Libera memoria al finalizar.

## Criterios de aceptacion

- El arreglo contiene exactamente los mismos datos que la lista.
- No hay fugas de memoria evidentes en ejecuciones repetidas.
