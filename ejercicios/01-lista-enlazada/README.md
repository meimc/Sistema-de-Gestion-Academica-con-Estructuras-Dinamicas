# Ejercicio 01 - Lista enlazada simple

## Objetivo

Implementar la gestion de estudiantes usando lista enlazada simple.

## Consigna

1. Define `Nodo` con `Estudiante data` y `Nodo* next`.
2. Implementa:
   - Insertar estudiante
   - Eliminar por `codigo`
   - Modificar por `codigo`
   - Mostrar todos
3. Evita codigos duplicados.

## Casos borde obligatorios

- Lista vacia.
- Eliminacion del primer nodo.
- Eliminacion del ultimo nodo.
- Codigo inexistente.

## Criterios de aceptacion

- Todas las operaciones mantienen la integridad de la lista.
- No hay crasheos por punteros nulos.
