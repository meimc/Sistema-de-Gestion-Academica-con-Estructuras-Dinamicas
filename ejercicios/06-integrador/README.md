# Ejercicio 06 - Integrador final

## Objetivo

Armar un mini sistema funcional que cumpla los requerimientos del README original.

## Consigna

Integra todo en un solo programa con menu:

1. Registro, eliminacion y modificacion de estudiantes (lista enlazada).
2. Copia a arreglo dinamico para ordenamientos.
3. Los 5 algoritmos de ordenamiento pedidos.
4. Busqueda lineal y binaria.
5. Funciones recursivas de promedio general e impresion.

## Checklist de entrega

- [ ] Gestion de estudiantes operativa
- [ ] Arreglo auxiliar funcionando
- [ ] 5 ordenamientos funcionando
- [ ] Busqueda lineal y binaria correctas
- [ ] Recursividad implementada
- [ ] Casos borde probados

## Meta de aprendizaje

Si llegas aca y podes defender tus decisiones de estructura y complejidad, estas para rendirlo bien.
