📌 PROYECTO 1 - Grupo 1

Sistema de Gestión Académica con Estructuras Dinámicas

🎯 Objetivo

Desarrollar un sistema que permita gestionar estudiantes, cursos y calificaciones utilizando arreglos y listas enlazadas, aplicando algoritmos de ordenamiento y búsqueda.

🔹 Requerimientos Funcionales:

1️⃣ Gestión de Estudiantes
* Cada estudiante debe tener:
* Código (int)
* Nombre (string)
* Promedio (float)
* Implementar:
* Registro de estudiantes (Lista enlazada simple)
* Eliminación por código
* Modificación de datos

2️⃣ Ordenamientos (sobre arreglo auxiliar)
Copiar los datos de la lista a un arreglo dinámico y permitir:
* Método burbuja (ordenar por promedio)
* Método selección (ordenar por código)
* Insertion Sort (ordenar por nombre)
* Quick Sort (ordenar por promedio)
* Merge Sort (ordenar por código)

Debe mostrarse el arreglo antes y después del ordenamiento.

3️⃣ Búsquedas
* Búsqueda lineal (sobre lista enlazada)
* Búsqueda binaria (sobre arreglo previamente ordenado)

4️⃣ Recursividad
Implementar:
* Función recursiva que calcule el promedio general del grupo
* Función recursiva que imprima los estudiantes

⚠️ Estructuras Obligatorias
* ✔ Lista enlazada simple
* ✔ Arreglos dinámicos
* ✔ Recursividad
* ✔ Todos los algoritmos de ordenamiento
* ✔ Búsqueda lineal y binaria
